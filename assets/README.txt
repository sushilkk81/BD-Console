Put the official Shaily logo here as:

    shaily-logo.png

The app automatically embeds it in the header (top-left of every screen) with no
design change. If this file is absent, the app falls back to a geometric S-mark SVG.

For the deployed Streamlit Cloud app, add assets/shaily-logo.png to the GitHub repo
under shaily-streamlit/assets/ and it will appear on the next redeploy.
